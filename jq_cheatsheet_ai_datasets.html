jq command reference for AI dataset inspection

Common patterns for JSONL fine-tuning data and API response files
inspect
View the keys of one record
head -n 1 dataset.jsonl | jq 'keys'
Shows field names in the first record — essential first step on any unknown dataset.
inspect
Pretty-print a single record
head -n 1 finetune.jsonl | jq '.'
Formats the raw JSON with indentation and color — much easier to read than raw JSONL.
inspect
Extract one field from every record
jq -r '.prompt' dataset.jsonl | head -20
-r gives raw strings (no quotes). Swap .prompt for any field name.
inspect
Check message structure (chat format)
head -n 1 chat_data.jsonl | jq '.messages[] | {role, content: .content[:80]}'
Previews each message's role and first 80 chars — useful for OpenAI/Anthropic fine-tune formats.
filter
Filter records by field value
jq 'select(.label == "toxic")' dataset.jsonl | wc -l
Count how many examples have a specific label — great for checking class balance.
filter
Filter by string length (find short responses)
jq 'select((.completion | length) < 20)' dataset.jsonl | head -5 | jq '.'
Surface potentially bad examples — very short completions often signal labeling errors.
filter
Find records missing a field
jq 'select(.completion == null or .completion == "")' dataset.jsonl | wc -l
Counts incomplete records before training — catches data pipeline issues early.
reshape
Extract unique label values
jq -r '.label' dataset.jsonl | sort -u
Lists every distinct label in your dataset — verify your classes match expectations.
reshape
Count label distribution
jq -r '.label' dataset.jsonl | sort | uniq -c | sort -rn
Shows label frequencies, sorted by count — instant class imbalance check.
reshape
Convert array JSON to JSONL
jq -c '.[]' dataset.json > dataset.jsonl
-c outputs compact (one record per line). Most training frameworks expect JSONL.
reshape
Reformat fields for fine-tuning
jq -c '{prompt: .input, completion: .output}' old.jsonl > ft.jsonl
Renames fields to match your training framework's expected schema.
