GPU utilization — 94%
How busy the GPU compute cores are. Target: 85–98% during training. Below 50% usually means a data loading bottleneck — your GPU is waiting on CPU.
Memory — 61432 / 81920 MiB
VRAM used vs total. Getting close to the limit causes OOM crashes. If memory is maxed but utilization is low, you have a memory fragmentation or batch size issue.
Temperature — 52°C, 312W
52°C is healthy for an A100 (safe up to ~83°C). Power draw of 312W/400W means the GPU isn't thermally throttling — it's running at near full power budget.
Perf state — P0
P0 = maximum performance mode. P8 would mean idle/low power. During training you always want P0. If you see P2–P8, the GPU may be throttling due to thermals or power limits.
