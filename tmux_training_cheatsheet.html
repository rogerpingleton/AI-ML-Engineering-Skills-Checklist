tmux — training session cheatsheet

Prefix key is Ctrl+B — press it before every keyboard shortcut below

Sessions
tmux new -s training
Start a new named session
tmux attach -t training
Reattach to an existing session
tmux ls
List all active sessions
tmux kill-session -t training
Destroy a session and all its processes
Detach & navigate (keyboard shortcuts)
Ctrl+B then d
Detach — leaves session running, returns to normal shell
Ctrl+B then c
Create a new window in current session
Ctrl+B then 0–9
Switch to window by number
Ctrl+B then n / p
Next / previous window
Ctrl+B then %
Split pane vertically
Ctrl+B then "
Split pane horizontally
Ctrl+B then arrow keys
Move between split panes
Ctrl+B then [
Scroll mode — use arrow keys, q to exit
Useful session flags
tmux attach -t training \ || tmux new -s training
Attach if exists, else create — safe to put in a script
tmux send-keys -t training \ "python train.py" Enter
Send a command to a session without attaching
