# AI/ML Career Launch Pad Engineering Skills Checklist
 
This checklist is part of the [AI/ML Career Launchpad](https://aiml-career-launchpad.circle.so) program created by Marina Wyss and used with permission. Specifically this Checklist is geared to those who are on the AI Engineering study track.

The content (links) were researched by me (Roger Pingleton) using Claude. I make no claims as to the accuracy the linked material or Python code. This list is designed as a quick reference to be used with Obsidian and contains Obsidian metadata which affects formatting in some documents.

Please feel free to improve the linked entries better by submitting suggestions/pull requests (rogermp8@gmail.com).

### Obsidian Use Case

The purpose of this project is to serve as study material for those of us who are in the AI/ML Career Launchpad engineering track program, as both a study guide and a source for my own pending personal skills test AI application.

In its simplest form, this repo can be cloned and used as an Obsidian vault. Open the "index.md" file in Obsidian (this is the actual checklist). 

Study a topic by clicking on a link. When you are confident as to your grasp of the subject matter, you can check the skill off of the list.
